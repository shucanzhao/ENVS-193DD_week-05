# ENVS-193DD_week-05
ENVS-193DD_week-05 Assignment


## General information
This repository contains the code, data, and rendered output for Individual Assignment 5.

The assignment uses aquatic invertebrate sampling data from the NCOS restoration site to visualize 
the site differences in copepod and ostracod abundance alongside salinity, combined into a multipanel figure 
and the relationship between log-transformed average abundance per liter and median salinity for every taxon in the cleaned dataset.

Author: Shucan Zhao

Date: 2026-05-10
